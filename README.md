# CHRONOS — камера, що бачить крізь час

Браузерний застосунок, який перетворює камеру телефона на «машину часу».
Чистий **WebGL2** без бібліотек: кожен кадр обробляється шейдерами на GPU, відео не залишає пристрій.

## Режими

| Режим | Що відбувається |
|---|---|
| **Рідкий час** | Застосунок пам’ятає останні ~2 секунди (60 кадрів у текстурному масиві). Кожен піксель показує свій момент минулого: каскад, портал, рідина або хвиля від дотику. Опція RGB-розшарування розводить канали кольору в часі — рух стає веселкою. |
| **Розлом часу** | Slit-scan: світна лінія сканує кадр і заморожує кожен рядок. Рухайтеся разом із нею — отримаєте сюрреалістичні «розтягнуті» портрети. |
| **Голограма** | Зображення розпадається на ~70 000 світних частинок у 3D (глибина з яскравості). Тягніть пальцем або нахиляйте телефон. |
| **Тепловізор** | Симуляція інфрачервоної камери: яскравість + рух = «тепло». Прицільна сітка з «температурою». |
| **Матриця** | Реальність із символів: ASCII-градієнт або цифровий дощ з катаканою. |
| **Світлопис** | Рух залишає неонові сліди, що повільно згасають. Махайте ліхтариком у темряві — малюйте світлом. |

**Світло (кнопка ⚡):** на основній камері вмикає справжній ліхтар телефона, якщо браузер це дозволяє. Для фронтальної камери, або коли ліхтар недоступний, екран світить білою кільцевою рамкою, як кільцева лампа. Фото в такому режимі знімаються зі спалахом екраном.

Також: фото (затвор), запис відео з ефектом (червона кнопка), «Поділитися» / «Зберегти», перемикання фронтальної/основної камери, свайп по екрану для зміни режиму, PWA (можна додати на головний екран).

## Запуск

Камера в браузері працює лише через **HTTPS** (або `localhost`).

**Локально:**
```bash
python3 -m http.server 8000
# відкрийте http://localhost:8000
```

**На телефоні через GitHub Pages:** Settings → Pages → *Deploy from a branch* → оберіть гілку та папку `/ (root)` → Save.
Через хвилину застосунок буде доступний за адресою `https://<user>.github.io/<repo>/`.

## Файли

- `index.html` — розмітка інтерфейсу
- `style.css` — дизайн (glassmorphism, анімації, safe-area для iPhone)
- `app.js` — WebGL2-рушій, шейдери, камера, фото/відео
- `sw.js`, `manifest.webmanifest`, `icons/` — PWA та офлайн-кеш

# БРУХТ — арена залізного хаосу (`/arena`)

Ретро-бойові перегони на машинах у браузері: low-poly 3D з піксельним рендером, дизерингом і «тремтінням» вершин, як на консолях 90-х.

- **Руйнування:** кузов м'ється в точці влучання, капот, двері, бампери, спойлери й колеса відриваються та розлітаються з фізикою. Підбита машина димить і горить, а знищена вибухає й лишає обгорілий кістяк. Ящики, бочки (вибухають ланцюжком), ліхтарі й конуси ламаються.
- **Фізика керування:** зчеплення шин, керований занос на ручнику, турбо, трампліни й польоти, плавна підвіска. Удари кутом розвертають машину, а важкі машини розкидають легкі.
- **4 машини:** ГРІМ (залп ракет), БУЛЬДОЗЕР (таран), ОСА (блискавка), ПРИВИД (мінне поле).
- **Зброя:** кулемет з автонаведенням, самонавідні, вогняні й потужні ракети, міни, ударна хвиля.
- **Онлайн:** WebRTC peer-to-peer (PeerJS). Створи кімнату, надішли друзям код або посилання `?join=КОД` — до 8 машин, боти доповнюють. Сервер не потрібен: досить GitHub Pages.
- **Керування:** клавіатура, геймпад або сенсорні кнопки на телефоні (горизонтально).

Адреса на Pages: `https://<user>.github.io/<repo>/arena/`
