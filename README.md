# Warlock Arena — браузерний прототип

Мультиплеєрна арена в дусі карти **Warlocks** з Warcraft 3: маги б'ються на круглій платформі посеред лави і виштовхують одне одного за край. Що більше шкоди ти отримав, то далі тебе відкидає. Платформа з часом звужується.

> Це **браузерний тестовий концепт**. Він потрібен, щоб перевірити, чи весело грати, і як працює мережа. **Повноцінна гра буде нативною (ПК/Steam)**, план у [`docs/ROADMAP.md`](docs/ROADMAP.md).

## Що вже є

- **Мультиплеєр до 8 гравців** у кімнатах з 4-літерним кодом, вхід за посиланням.
- **Авторитетний сервер:** клієнт надсилає лише наміри, тож змахлювати важче.
- **10 спелів:** вогняна куля, блискавка, самонавідна ракета, телепорт, ривок, гравітаційна сфера, дзеркальний щит, обмін місцями, метеор, крижана хвиля.
- **Кастомізація:** кожен гравець збирає свій набір із 4 спелів (+ вогняна куля на Q) і обирає колір.
- **Прокачка між раундами:** золото за кілли, шкоду й перемоги. За нього купуються рівні спелів (до ★★★) і характеристики (живучість, швидкість, стійкість до відкидання).
- **Режими:** «кожен сам за себе» і командний (2×2 / 3×3, без дружнього вогню).
- **Мутатори:** крижана арена, швидкі перезарядки, хаос (подвійне відкидання).
- **Боти:** можна тестувати гру самому.
- Снаряди збивають одне одного, щит відбиває їх назад, а відкидання росте з отриманою шкодою (як у Smash Bros).

## Керування

| Дія | Клавіша |
|---|---|
| Рух | ЛКМ / ПКМ (можна тримати) |
| Спели (у бік курсора) | `Q` `W` `E` `R` `F` (або `1`–`5`) |
| Зупинитися | `S` |

Працює на будь-якій розкладці, зокрема кириличній, бо гра читає фізичні клавіші.

## Запуск

Потрібен Node.js 18 або новіший.

```bash
npm install
npm start          # http://localhost:3000
```

Відкрий сторінку, натисни «Створити кімнату» і скопіюй посилання. Друзі в тій самій мережі заходять за адресою `http://<твій-IP>:3000/?room=КОД`.

### Грати з друзями через інтернет

Найшвидший варіант — тунель, нічого не треба деплоїти:

```bash
npx cloudflared tunnel --url http://localhost:3000   # дасть https://xxxx.trycloudflare.com
```

Постійний хостинг: будь-який сервіс, що запускає Node.js з підтримкою WebSocket (Render, Railway, Fly.io, VPS). Команда запуску `npm start`, порт береться зі змінної `PORT`.

## Структура

```
shared/config.js   — увесь баланс і дані спелів (спільні для сервера й клієнта)
server/index.js    — HTTP-статика + WebSocket, кімнати
server/game.js     — авторитетна симуляція: фізика, спели, раунди, магазин, боти
client/            — Canvas-рендер, інтерполяція, UI (без збірки, чистий JS)
docs/              — дослідження, план, правила роботи агентів
```
