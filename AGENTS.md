# AGENTS.md — правила для AI-агентів

Єдине джерело правди для всіх агентів у цьому репозиторії. Codex/ChatGPT читає цей файл напряму, а Claude Code підтягує його через `CLAUDE.md`.

## Проєкт
Warlock Arena: мультиплеєрна арена в дусі Warlocks (WC3).
- **Повна гра — нативна (ПК/Steam).** Рушій пропонується Godot 4 + C# (див. `docs/DECISIONS.md` №7).
- **У репозиторії зараз браузерний прототип** на Node.js + `ws` і Canvas 2D без збірки. Він служить для плейтестів і балансу.

## Перед початком роботи
1. Прочитай `docs/STATUS.md`: поточний стан, хто що робить, відкриті питання.
2. Прочитай `docs/DECISIONS.md`: прийняті рішення. Не переглядай їх без запису нового рішення.
3. Задачу бери з `docs/STATUS.md` → «Черга». Познач, що вона в роботі, і вкажи, який агент її взяв.

## Ролі (за замовчуванням)
- **Claude Code — виконавець.** Реалізує задачі, пише й запускає тести, комітить у свою гілку.
- **Codex / ChatGPT — рев'юер і дизайнер.** Рев'ю диффів і PR, баланс спелів, генерація ідей та специфікацій у `docs/specs/`.
- Агенти не працюють одночасно в одних і тих самих файлах. Кожен працює у своїй гілці (`claude/*`, `codex/*`) або git worktree.

## Правила коду
- Баланс і дані тримаються лише в `shared/config.js` (data-driven). Логіка не містить магічних чисел спелів.
- Сервер авторитетний: клієнт ніколи не вирішує, чи було влучання, скільки шкоди, чи є кулдаун.
- Будь-яке нове повідомлення протоколу треба валідувати на сервері (`Room.handle`).
- Тексти інтерфейсу пиши українською.
- Перед комітом:
  - `node --check` на змінених файлах;
  - прогін симуляції `node scripts/sim.mjs`: всі режими мають дійти до `gameOver`.

## Після роботи
- Онови `docs/STATUS.md`: що зроблено, що далі, що зламано.
- Нове архітектурне рішення додай у `docs/DECISIONS.md` (1–3 рядки: контекст → рішення → чому).
- Повідомлення комітів пиши у форматі `тип: опис` (feat/fix/balance/docs/refactor).
