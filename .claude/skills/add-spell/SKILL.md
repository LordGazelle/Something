# Додавання спела

1. **Дані** → `shared/config.js`, об'єкт `SPELLS`.
   Додай запис з полями `name`, `kind`, `icon`, `color`, `cd`, `desc` та полями свого типу.
   Якщо підходить існуючий `kind` (`projectile`, `beam`, `blink`, `dash`, `shield`, `meteor`, `nova`), просто перевикористай його. Тоді код не потрібен, вистачить прапорців типу `homing`, `swap`, `field`.
2. **Новий `kind`** → `server/game.js`:
   - `Room.cast()`: нова гілка `case`;
   - якщо є стан у часі, додай зону в `updateZones()` або поле гравця в `simulate()`;
   - шкоду завдавай лише через `this.hit()`, щоб працювали множник відкидання, кредит за кіл і мутатори.
3. **Бот** → `Room.botThink()`: умова, коли бот кастує новий `kind`.
4. **Рендер** → `client/render.js`:
   - снаряд малюється автоматично;
   - для зони додай гілку в `drawZone()`;
   - для одноразового ефекту додай `this.events.push({t:...})` на сервері та `case` у `Renderer.event()`.
5. **Перевірка:**
   - `node --check` на змінених файлах;
   - `npm run sim`: усі режими мають дійти до `gameOver`;
   - запусти `npm start` і подивись спел наживо.
6. Онови `docs/STATUS.md`.

Правило балансу: що сильніший ефект відкидання, то довший кулдаун. Орієнтир: `knock × частота ≈ 250–350/с`.
