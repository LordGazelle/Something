# Roadmap: від прототипу до гри

## Фаза 0 — Прототип ✅ (цей репозиторій)
Перевіряємо, чи кор-геймплей веселий: відкидання, лава, спели, раунди з магазином.

## Фаза 1 — Плейтест і ТЗ (1–2 тижні)
- 3–5 сесій з живими гравцями. Записати, що весело, що дратує, які спели імба.
- **GDD** (`docs/specs/GDD.md`):
  - кор-луп;
  - список спелів і їхні ролі (контроль / мобільність / шкода / захист);
  - режими;
  - мета-прогресія (що відкривається між матчами, а що всередині матчу);
  - монетизація (лише косметика).
- **TDD** (`docs/specs/TDD.md`): стек, мережева модель, схема даних, CI.
- Візуальний напрям: мудборд, 2D top-down чи 3D з ізометрією.

## Фаза 2 — Фундамент (3–4 тижні)
- Монорепозиторій на TypeScript:
  - `packages/shared` — детермінована симуляція й дані спелів;
  - `server` — Colyseus;
  - `client` — Phaser 4 або PixiJS.
- Клієнтське передбачення власного руху та узгодження із сервером (reconciliation).
- Бінарні дельта-знімки (Colyseus Schema).
- Тести симуляції (Vitest) + Playwright e2e + CI на GitHub Actions.

## Фаза 3 — Контент і реіграбельність
- 20+ спелів з комбо-взаємодіями (наприклад, лід + вогонь = пара).
- Різні арени: перешкоди, ями, рухомі платформи, різні форми звуження.
- Режими:
  - FFA;
  - команди;
  - King of the Hill;
  - «Картопля-бомба»;
  - драфт спелів (гравці по черзі обирають із спільного пулу);
  - рандомні набори.
- Мутатори раунду: випадкова подія кожні N секунд.
- Реліквії/перки між раундами (roguelite-шар): вибір 1 з 3 випадкових.

## Фаза 4 — Мета й соціальне
- Акаунти, рівень профілю, відкриття спелів і скінів, щоденні завдання.
- Косметика: скіни магів, ефекти спелів, сліди, емоції.
- Матчмейкінг за рейтингом (Glicko-2), приватні кімнати, друзі, спостерігачі, повтори матчів.

## Фаза 5 — Реліз
- Ітч.іо / CrazyGames / Poki для швидкого охоплення, далі власний домен.
- Можлива обгортка для Steam (Electron / Tauri).
