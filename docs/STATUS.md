# STATUS — пам'ять проєкту між сесіями

_Оновлюй у кінці кожної сесії. Коротко._

## Поточний стан
- Прототип v0.1 працює:
  - мультиплеєр у кімнатах;
  - 10 спелів;
  - режими FFA / команди;
  - 3 мутатори;
  - магазин і прокачка між раундами;
  - боти.
- Перевірено: 2 браузерні клієнти + боти (Playwright) і headless-симуляція всіх режимів (`npm run sim`).

## Відомі обмеження прототипу
- Немає клієнтського передбачення: власний рух відчувається із затримкою ~100 мс + пінг.
- Стан у пам'яті сервера: після рестарту прогрес зникає, акаунтів немає.
- JSON-знімки без дельта-компресії. Для 8 гравців цього досить, для масштабу — ні.
- Немає звуку і мобільного керування.
